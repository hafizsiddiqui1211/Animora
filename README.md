# Animora — Ultrasonic 5D Website

A production-ready React/Vite concept for Animora with:

- Motion for React (the current successor to Framer Motion)
- Responsive multi-page routing
- 5D-inspired layered depth / parallax orb
- Canvas neural-field particles and dimensional wave ribbons
- Scroll reveals, hover physics, page navigation and micro-interactions
- Animora social links wired to TikTok, YouTube, Facebook, Instagram and LinkedIn
- Reduced-motion support
- No image assets required for the initial build

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
npm run preview
```

## Pages

- `/` — cinematic landing page
- `/stories` — story universe
- `/worlds` — original worlds
- `/about` — studio positioning
- `/connect` — social hub

## Motion

The project uses `motion` and imports from `motion/react`, matching the current Motion for React documentation.
